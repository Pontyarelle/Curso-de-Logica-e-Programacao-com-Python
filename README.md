# Curso de Lógica e Programação com Python

Repositório de estudos, exemplos de código e atividades práticas desenvolvidos durante o curso de **Lógica e Programação**, utilizando a linguagem **Python**.

O objetivo é desenvolver o raciocínio lógico e aprender a construir algoritmos e programas, partindo dos conceitos fundamentais até a resolução de problemas por meio de código.

## Objetivos do curso

- Compreender os conceitos fundamentais de lógica de programação.
- Desenvolver algoritmos para resolver problemas.
- Conhecer a sintaxe e os recursos básicos da linguagem Python.
- Utilizar variáveis, operadores, estruturas condicionais e de repetição.
- Trabalhar com coleções de dados e funções.
- Realizar operações de entrada e saída e manipular arquivos.
- Desenvolver pequenos projetos para aplicar os conhecimentos adquiridos.
- Utilizar o Git e o GitHub para versionar e compartilhar códigos.

## Organização das aulas

Cada pasta ou arquivo deste repositório poderá conter códigos demonstrativos, exercícios, desafios e materiais utilizados na respectiva aula.

### Aula 01 — Introdução à lógica de programação
1. O que é lógica de programação?
2. O que é um algoritmo?
3. Problemas, dados, processamento e resultados.
4. Formas de representar algoritmos: descrição narrativa, fluxograma e pseudocódigo.
5. Noções de sequência lógica e resolução de problemas.
6. Primeiro contato com exemplos de algoritmos do cotidiano.

### Aula 02 — Introdução ao Python e configuração do ambiente
1. O que é Python e onde é utilizado?
2. Instalação e configuração do Python.
3. Instalação e configuração do Visual Studio Code.
4. Extensão Python no VS Code.
5. Criação e execução do primeiro programa.
6. Função `print()` e comentários no código.

### Aula 03 — Variáveis, tipos de dados e entrada de informações
1. O conceito de variável.
2. Regras para nomear variáveis.
3. Tipos de dados: `int`, `float`, `str` e `bool`.
4. A função `input()`.
5. Conversão de tipos com `int()`, `float()` e `str()`.
6. Exibição de resultados com `print()` e f-strings.

### Aula 04 — Operadores em Python
1. Operadores aritméticos.
2. Operadores relacionais ou de comparação.
3. Operadores lógicos: `and`, `or` e `not`.
4. Operadores de atribuição.
5. Precedência dos operadores.
6. Construção de expressões e cálculos.

### Aula 05 — Estruturas condicionais
1. Tomada de decisão em algoritmos.
2. Estrutura `if`.
3. Estrutura `else`.
4. Estrutura `elif`.
5. Condições simples e compostas.
6. Condicionais aninhadas.
7. Aplicações práticas: médias, descontos, aprovação e classificação.

### Aula 06 — Estruturas de repetição
1. O conceito de laço de repetição.
2. Estrutura `while`.
3. Estrutura `for`.
4. Função `range()`.
5. Uso de contadores e acumuladores.
6. Comandos `break` e `continue`.
7. Repetições controladas por condição e por quantidade.

### Aula 07 — Strings e manipulação de texto
1. O que são strings?
2. Acesso a caracteres e índices.
3. Fatiamento de strings.
4. Métodos `upper()`, `lower()`, `strip()` e `replace()`.
5. Verificação de conteúdo com `in`.
6. Formatação e concatenação de textos.

### Aula 08 — Listas e tuplas
1. Conceito de coleções de dados.
2. Criação e acesso a listas.
3. Índices e fatiamento.
4. Métodos `append()`, `insert()`, `remove()` e `pop()`.
5. Percorrendo listas com `for`.
6. Introdução às tuplas e suas diferenças em relação às listas.
7. Aplicações: cadastro e organização de informações.

### Aula 09 — Dicionários e conjuntos
1. Conceito de dicionário.
2. Estrutura de chave e valor.
3. Criação, consulta, inclusão, alteração e remoção de elementos.
4. Métodos `keys()`, `values()` e `items()`.
5. Percorrendo dicionários com laços.
6. Introdução aos conjuntos (`set`).
7. Operações básicas com conjuntos.

### Aula 10 — Funções
1. O que são funções e por que utilizá-las?
2. Definição de funções com `def`.
3. Parâmetros e argumentos.
4. Retorno de valores com `return`.
5. Funções com e sem parâmetros.
6. Escopo de variáveis: local e global.
7. Organização e reutilização de código.

### Aula 11 — Modularização e tratamento de erros
1. Organização do programa em partes menores.
2. Importação de módulos com `import`.
3. Módulos da biblioteca padrão.
4. Criação e utilização de módulos próprios.
5. Erros de sintaxe e erros durante a execução.
6. Tratamento de exceções com `try`, `except` e `finally`.
7. Validação de dados informados pelo usuário.

### Aula 12 — Manipulação de arquivos
1. O que é manipulação de arquivos?
2. Abertura e fechamento de arquivos.
3. Modos de abertura: leitura, escrita e adição.
4. Leitura de arquivos com `read()` e `readlines()`.
5. Escrita com `write()`.
6. Utilização de `with open()`.
7. Armazenamento e recuperação de informações em arquivos de texto.

### Aula 13 — Introdução à programação orientada a objetos
1. Conceitos de classe e objeto.
2. Atributos e métodos.
3. Criação de classes em Python.
4. Método construtor `__init__()`.
5. Instanciação e utilização de objetos.
6. Exemplos simples de modelagem de situações do cotidiano.

### Aula 14 — Desenvolvimento de algoritmos e resolução de problemas
1. Interpretação e decomposição de problemas.
2. Identificação de entradas, processamento e saídas.
3. Escolha de estruturas de dados.
4. Planejamento da solução antes da codificação.
5. Implementação e testes.
6. Depuração e melhoria do código.
7. Desafios práticos integrando os conteúdos do curso.

### Aula 15 — Git e GitHub: versionamento de projetos
1. O que é controle de versão?
2. Diferenças entre Git e GitHub.
3. Instalação e configuração inicial do Git.
4. Criação de uma conta e de um repositório no GitHub.
5. Configuração de usuário e e-mail no Git.
6. Comandos básicos: `git init`, `git status`, `git add` e `git commit`.
7. Conexão com repositório remoto: `git remote` e `git push`.
8. Clonagem e atualização de projetos com `git clone` e `git pull`.
9. Envio de projetos do VS Code para o GitHub.
10. Documentação de projetos com `README.md`.

### Aula 16 — Projeto prático final
1. Definição do problema que será resolvido.
2. Levantamento dos requisitos do programa.
3. Planejamento do algoritmo.
4. Desenvolvimento da solução em Python.
5. Utilização de funções e estruturas de dados.
6. Testes, identificação e correção de erros.
7. Organização dos arquivos do projeto.
8. Publicação do código no GitHub.
9. Apresentação e demonstração do projeto.


## Como utilizar este repositório

1. Faça o download do projeto ou clone o repositório:
   ```bash
   git clone URL_DO_REPOSITORIO
   ```
2. Abra a pasta do projeto no Visual Studio Code.
3. Acesse a pasta da aula desejada.
4. Execute os arquivos Python pelo terminal ou pelo próprio VS Code.
5. Pratique os exemplos e resolva as atividades propostas.

## Requisitos

- Python 3 instalado.
- Visual Studio Code (recomendado).
- Git instalado para versionamento e envio dos projetos ao GitHub.
